# Persian AI — Neural Chatbot
A Persian chatbot powered by a GPT-style decoder-only transformer trained from scratch.
No scripted/canned responses — every answer is generated by the model.

## Architecture
- **GPT-style decoder-only transformer** (next-token prediction with causal masking)
- Loss computed only on response tokens via `<bos> question <sep> answer <eos>` template
- Word-level tokenizer (top-20K vocabulary), learned positional embeddings
- Trained on ~150K unique Persian Q&A pairs sampled from a 420K-pair corpus
- Flask + pywebview dedicated desktop window, multi-session chat history

## Dataset (~102MB, 421K unique pairs)
Built by `scripts/build_dataset.py` from:
| Source | Pairs | License |
|---|---|---|
| ParsBench/PersianSyntheticQA (HF) | ~45K | Apache-2.0 |
| Heydaritoday/Persian-Synthetic-Instruct (HF) | ~3K | Apache-2.0 |
| Original `mydataset_500k.txt` (deduplicated) | ~376K | — |

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt pyarrow
```

2. Build the dataset (downloads from HuggingFace + merges local data):
```bash
python scripts/build_dataset.py
```

3. Run the app:
```bash
python app.py
```

**Notes:**
- On first launch the model trains in a background thread (~20–40 min on CPU).
  The window opens immediately; answers improve once training finishes.
- Subsequent launches load the checkpoint instantly.
- Chat sessions are saved in the `sessions/` folder.
